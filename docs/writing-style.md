# 文章の規約

「落ち着いている」を「暗い」と取り違えない。
情報が多くて視覚が静かなのはデザインの話であって、文章まで静かにする必要はない。

読者に起こしたいのは三つだけ。

- 行ってみたい
- 観てみたい
- もっと知りたい

これが起きない文章は、どれだけ正確でも失敗とみなす。

この文書は**記事の構成と態度**を決める。
一文の骨格（主語、主体、固有名詞、文末、数値）は `japanese-prose.md` にある。
一覧の一行や要約など、記事の外に出るテキストは、そちらが適用範囲になる。

---

## 絶対にやらないこと — わくわくのために事実を作らない

**これが最優先の規約である。** 前の三つより上に置く。

文章を面白くしようとすると、書き手は「その場にいた人の書き方」を真似したくなる。
だが、行っていない場所の体感と、観ていない舞台の音を書いてはいけない。

実際にやってしまった例を残しておく。

> 捏造： 小さな子方が、大人のシテを本当に翻弄する。薙刀と小太刀がぶつかる音が客席まで届く。

能の立ち回りは様式化されている。刀が激しくぶつかって音が響く殺陣ではない。
これを読んで劇場へ行った人は、確実に失望する。
「正直に書く」と宣言しながら、いちばん不正直なことをしている。

> 捏造： 二月の安宅は、砂が真横に飛んでくる。十分も立っていると顔が痛い。
> 捏造： 松原橋の欄干から下を覗くと、水面までが思ったより近い。
> 捏造： 夜に来ると、街灯の間隔が広いことに気づく。

どれも行っていない。書いた人間の想像である。

### 代わりに書けること

| 書ける | 書けない |
| --- | --- |
| 駅から徒歩 何分（公開情報） | 坂がきつい（登っていない） |
| 冬の日本海側は季節風が強い（気候の事実） | 顔が痛い（当たっていない） |
| 木の根が露出した道がある（知られた景観） | 足の置き場を探すことになる（歩いていない） |
| 上演時間の目安（番組表） | 客席が静まる（座っていない） |
| 子方が演じる（曲の約束ごと） | まばたきすると終わっている（観ていない） |

### 取材していないことは、取材していないと書く

本サイトは史料について「どの層の情報か」を毎回示している。
現在の情報にも同じ規律を適用する。

現地を歩いていないなら、記事にそう書く。
公開情報から構成したものは、そう書く。
これは弱点の告白ではなく、このサイトの方法そのものである。

わくわくは、嘘からではなく、**本当に変なこと**から作る。
能には本当に変なことが十分にある。子どもが主君を演じて一言も喋らない、
白紙の巻物を朗々と読む、勝った武将が地獄で苦しんでいる。
作る必要はない。

## 文体 — です・ます調で、読者に向かって書く

### である調をやめる

である調で書くと、読者に説明している文章ではなく、書き手が自分に向かって呟いている文章になります。
そこに体言止めと倒置が加わると、気難しい人が独りで納得している気配が出ます。

本サイトは **です・ます調** で統一します。

> 変更前： 曲は短い。四十分ほどで終わる。
> 変更後： この曲は短くて、四十分ほどで終わります。

### 語尾だけ変えても直らない

です・ます調にしたうえで、文の作りも変えます。

**体言止めを使わない。**

> 変更前： 夜。橋。正体不明。常人離れした速度。
> 変更後： 夜の橋に、正体の分からない相手がいて、しかも異様に速い。

**倒置を使わない。**

> 変更前： 説明されないことに気づけるかどうかが、この短い曲の入口になっている。
> 変更後： 舞台では誰もそのことを説明しません。そこに気づけるかどうかが、この曲の入口です。

**短文を並べて余韻を作らない。**
切るのは、本当に効かせたい一か所だけにします。

### 評定する口調をやめる

次の言い回しは、読者を見下ろす位置から書いています。

| 使わない | 代わりに |
| --- | --- |
| 〜と見てよい | 〜と言われています／〜と考えられています |
| 〜と考えるのが妥当だろう | 〜という見方が有力です |
| 押さえておきたい | ここが大事なところです |
| 断っておきたい | 先に書いておきます |
| 目を向けておきたい | ついでに見ておくと |
| 〜に見える | 〜のように思えます |

### 像が浮かぶように書く

「イメージがつきにくい」と言われたら、たいてい原因は三つです。

1. 誰が何をしたのかが曖昧（主語を書く）
2. 抽象的な整理から入っている（場面から入る）
3. 言い換えや比喩で処理している（そのまま書く）

> 変更前： 社会の尺度を代表する成人が、全力で向かって、届かない。
> 変更後： 大人の弁慶が本気で向かっていって、それでも届きません。

段落の最初の一文で「これから何の話をするか」を言います。
もったいぶって最後に置かない。

### 例外 — 問いと見出し

記事の冒頭に置く問いと、章の見出しは、平叙の疑問形のままにします。

> 弁慶は、なぜ負けなければならなかったのか。

これは見出しであって地の文ではないので、です・ます調にすると間延びします。
逆に、地の文のなかで問いかけるときは です・ます調にそろえます。

> 常識の側にいる男が敗れることには、どんな意味があるのでしょうか。

### ただし、丁寧すぎて眠くならないように

です・ます調は、放っておくと説明書の文章になります。
一記事に一、二か所、書き手の体温を出します。

> ここが、この曲でいちばん好きなところです。
> 正直に言うと、前半は退屈します。

## やめること

### 1. 短い断定を並べて「間」を作る

悪い例。

> 幕が下りる。それだけである。
> 問題はその先にある。

かっこうはつくが、読者は何も感じない。
一文を切るのは、本当に効かせたい一か所だけにする。

### 2. 体温のない留保

「〜と考えられる」「〜と言える」「〜であろう」を無意識に置かない。
学術的な慎重さは、断定を避けることではなく**出典を示すこと**で担保する。

留保するなら、何が分かっていないのかを具体的に書く。

> 悪い： 〜だったと考えられる。
> よい： ここは分かっていない。いつ誰が始めたのかを示す史料がない。

### 3. 感覚のない現地描写

> 悪い： 冬は風が強い。
> よい： 日本海に面した砂丘で、冬は季節風がまともに当たります。

ただし、行っていない場所の体感は書きません（上の規約）。

数字、距離、時間、温度、音、匂い。
体が想像できないことは書いたことにならない。

### 4. 答えを先に置く

謎解きの快感は順序で決まる。
結論から入らず、読者が引っかかる順に出す。

> 悪い： 能では加害者が逆になっている。理由は三つある。
> よい： 二行目でおかしいと気づく。斬っているのが、大男のほうではない。

### 5. 舞台の上で何が起きるかを書かない

「観てみたい」を作るのは解釈ではなく、動きと音である。
薙刀が鳴る、子どもが跳ぶ、囃子が入る、沈黙が続く。
そこを書かずに演出論だけ書くと、誰も劇場へ行かない。

## やること

### 具体を出す

所要時間、料金の目安、駅からの分数、坂の傾き、席の埋まり方。
実用情報は野暮ではない。行くかどうかを決めるのはそこ。

### 正直に書く

> 正直に言うと、前半は眠くなる。
> 何もない。本当に何もない場所である。

弱点を隠すと、全部が宣伝文に見える。
書き手が正直だと分かると、褒めたときに信用される。

### 筆者の体温を少しだけ出す

「興味深い」ではなく「ここが一番好きだ」。
ただし一記事に一、二か所まで。多いと感傷になる。

### 一文の長さに幅をつける

短文ばかりは説教くさく、長文ばかりは読めない。
長めの一文で流れを作り、切りたいところだけ短くする。

## 使ってよい / いけない語

避ける。

- 驚くべきことに / 実は / 衝撃 / 日本人なら知っておきたい
- 幽玄 / 侘び寂び を説明なしに使う
- 「〜なのである」の多用

使ってよい。

- 面白い、好きだ、気持ちがいい、拍子抜けする、ぞっとする
- 具体的な数字と固有名詞

## 章ごとの役割

| 章 | 役割 | 失敗の形 |
| --- | --- | --- |
| 問い | 引っかかりを作る | 要約になっている |
| LEAD | 読む理由を渡す | あらすじになっている |
| 01 ON STAGE | 舞台で何が起きるか。音と動き | 筋書きの説明で終わる |
| WATCH | 初めて観るとき、どこを見るか | 書いていない |
| 中盤 | 謎を解く順序で並べる | 結論から入る |
| PLACE | 行きたくさせる。体感と実用 | 場所の説明で終わる |
